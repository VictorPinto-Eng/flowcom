# Squad Configuration for flowcom

This directory contains the multi-agent squad configuration for the flowcom project.

## Structure

- `SQUAD.md` - Main squad documentation and protocols
- `agents/` - Individual agent personas and specializations
  - `coordenador.md` - Project coordinator agent
  - `designer.md` - UI/UX designer agent
  - `engenheiro.md` - Software engineer agent
  - `pesquisador.md` - Research agent
  - `qa.md` - Quality assurance agent
  - `seguranca.md` - Security agent

## Usage

When working on this project, you can invoke specific agents by mentioning their role or use the squad system for complex tasks.

## Project Context

- **Project**: flowcom (Next.js 16 with PostgreSQL/Prisma)
- **Domain**: Activity/board management system
- **Tech Stack**: Next.js, React 19, Prisma, PostgreSQL, SweetAlert2
